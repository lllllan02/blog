> [CS自学指南](https://csdiy.wiki/)

以下是精选的高质量大学计算机必修课及 Golang 后端开发专项课程资源，适合从 CS50 进阶到专业后端开发。

**阶段一：工具与基础 (磨刀不误砍柴工)**

**阶段二：计算机系统核心 (后端内功)**

  - [ ] 第 13-14 章：虚拟内存
  - [ ] 第 26 章：并发入门
  - [ ] 第 36-37 章：磁盘与 I/O 概览
- 《计算机网络：自顶向下方法》
  - [ ] [配套视频](https://www.youtube.com/playlist?list=PL1ya5dD_M8uX-BLUF1FEvUNsYWQL5_l0O)
- **数据库**（概念为主）
  - [ ] 《数据库系统概念》索引、事务部分
  - [ ] [CMU 15-445](https://www.youtube.com/playlist?list=PLSE8ODhjZXjbj8BMuIrRcacnQh20hmY9g)（偏深入，可选）

**阶段三：Golang 进阶与分布式系统 (核心竞争力)**

- [ ] [Rob Pike: 并发不是并行 (Concurrency is not Parallelism)](https://www.youtube.com/watch?v=oV9rvDllKEg)
- [ ] [Dave Cheney: Solid Go 设计模式 (Solid Go Design)](https://www.youtube.com/watch?v=zzAdEt3xZ1M)
