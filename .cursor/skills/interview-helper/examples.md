# Interview Helper Examples

本文件提供可复制的“回复模板”与少量输入输出示例，用于面试题助手生成文章/卡片类内容时直接套用。

## 回复模板（文章/卡片类）

```markdown
---
title: [标题：一句话概括问题与结论]
aliases: [UUID v4]
date: [YYYY-MM-DD HH:mm:ss]
card: true
order: 100
tags:
  - [技术标签]
---

## 核心解答
[一句话/两句话给出面试可直接复述的结论]

## 解答思路
- [从定义/目标出发的推导步骤]
- [关键对比点：A vs B]
- [必要的前置假设/适用范围]

## 深度解析与面试技巧
### 深度解析
- [底层原理/机制/实现要点]
- [边界情况与常见坑]
- [性能与工程取舍]

### 面试技巧
- **面试官可能追问**：
  - [追问 1]
  - [追问 2]
- **常见误区**：
  - [误区 1]：为什么错，正确说法是什么
  - [误区 2]

:::: [!info]- 扩展内容（可选）
[把非核心但有价值的补充放这里，默认折叠]
::::
```

## 示例 1：输入（用户提问）

```text
回答：Go 的 goroutine 栈为什么能从小栈开始？会有什么代价？
```

## 示例 1：输出（结构示意）

- `## 核心解答`：先讲“分段栈/可增长栈”的核心机制与收益
- `## 解答思路`：从“为什么不能一开始就给大栈”推导到“按需增长”
- `## 深度解析与面试技巧`：补充栈拷贝/栈扫描/抢占等可能追问与误区
