# Callout (提示块) 格式规范参考

在本项目中，Callout (提示块) 主要用于**补充重点内容**或作为**文档的引申扩展**。请严格按照下述格式在 Markdown 文档中使用。

## 1. 基础语法

Callout 必须使用三个冒号 `:::` 包裹，并在第一行使用 `[!type]` 来声明提示块的类型，然后可选地加上纯中文标题（支持专有名词包含英文）。

```markdown
::: [!note] 补充说明
这里是提示块的内部内容，可以包含 **加粗**、[链接](#)、甚至代码块。
:::
```

> **严格要求：** 必须确保首尾的 `:::` 独立成行。

## 2. 折叠 (Collapsible) 语法

支持将提示块设置为可折叠，用于包裹大量补充说明、代码示例或非主线阅读内容。
在 `[!type]` 后面加上 `+` 或 `-` 即可实现折叠：
- `+`：默认**展开**
- `-`：默认**折叠**

```markdown
::: [!tip]- 默认折叠的提示块
这是一些补充信息或扩展阅读，默认收起以免占据过多篇幅。
:::

::: [!warning]+ 默认展开的折叠块
这里是一些重要的警告信息。
:::
```

## 3. 支持的类型 (Types)

支持多种映射类型（大小写不敏感），不同类型会渲染不同的图标和主题色。常用类型如下：

- **建议/提示**：`tip`, `hint`, `important`
- **笔记/信息**：`note`, `info`, `abstract`, `summary`, `tldr`
- **问题/疑问**：`question`, `help`, `faq`
- **成功/完成**：`success`, `check`, `done`
- **警告/注意**：`warning`, `attention`, `caution`
- **失败/错误/危险**：`failure`, `missing`, `fail`, `danger`, `error`, `bug`
- **其他**：`todo`, `example`, `quote`, `cite`

## 4. 使用建议与限制

1. **控制使用频率**：请**不要**把文章的主干逻辑或大段常规正文放进 Callout 里，以免产生阅读疲劳。
2. **格式嵌套**：内部支持普通 Markdown 语法（代码块、列表、高亮等），但请保持排版整洁。
