# Quality Assurance Checklist

在提交或完成文档编写前，请对照此清单进行自检。

## 1. Metadata & Structure (元数据与结构)
- [ ] **Frontmatter 完整性**：包含 `title`, `aliases` (UUID), `date` 等必要字段。
- [ ] **UUID 唯一性**：`aliases` 中的 UUID 不与现有文档冲突。
- [ ] **标题层级**：从 H2 开始，无跳级（如 H2 -> H4），无 H1。
- [ ] **标题格式**：标题中无 Emoji，无代码块格式。

## 2. Formatting & Style (格式与风格)
- [ ] **中英文空格**：所有汉字与英文/数字间均有空格。
- [ ] **空行**：标题、段落、代码块、列表之间均有空行分隔。
- [ ] **代码块**：所有代码块均指定了语言标签。长代码已折叠。
- [ ] **Callout**：长内容/扩展内容已默认折叠 (`-`)。
- [ ] **链接**：内部链接使用了 UUID 格式 `[[uuid|title]]`。

## 3. Content Quality (内容质量)
- [ ] **简洁性**：是否可以用列表替代长段落？
- [ ] **清晰度**：是否去除了无意义的填充词（"废话"）？
- [ ] **原子性**：每个 Callout 或段落是否只讲了一件事？
- [ ] **语气**：是否保持了客观、专业的语气？

## 4. Linting (模拟检查)
- [ ] **MD009**：行尾无多余空格。
- [ ] **MD031**：代码块周围有空行。
- [ ] **MD040**：代码块有语言标识。
