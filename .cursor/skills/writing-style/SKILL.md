# ✍️ Writing Style Guide

**⚠️ 核心准则：本指南定义了当前项目（特别是 `content/` 目录下）所有 Markdown 文件的标准写作格式。在生成、撰写、修改或优化文档时，必须严格遵守以下规范。绝不妥协！**

## 1. 元数据与初始化 (Frontmatter)

### 1.1 文档初始化
新建文档时，优先使用项目 CLI 工具以自动生成标准格式：
- **普通文档**：`./clitool new doc "filename" --title "标题" --dir "content/..."`
- **卡片文档**：`./clitool new card "filename" ...`
- **Wiki 文档**：`./clitool new wiki "filename" ...`

### 1.2 Frontmatter 字段规范
若手动创建或修改文档，顶部的 YAML Frontmatter **必须**包含以下所有字段（允许值为空）：
- `title`: 文档标题（**必须是纯中文**，不可译的专有名词除外）。
- `aliases`: 全局唯一的 UUID（作为双链固定标识，**严禁随意更改**）。
- `date`: 创建时间，严格遵守 `YYYY-MM-DD HH:mm:ss` 格式。
- `card`: 布尔值（`true` 或 `false`），标识是否为卡片形式。
- `order`: 数字（选填具体数值，但**必须保留该字段**供排序使用）。
- `tags`: 标签列表（根据内容合理补充相关技术标签）。

## 2. 标题与结构规范

### 2.1 标题格式
- **禁用一级标题 (H1)**：正文中**严禁**使用 `#`。文章的 H1 已由框架根据 Frontmatter 的 `title` 自动渲染。
- **纯文本标题**：标题中**严禁**使用代码块、加粗、斜体等任何 Markdown 特殊格式。
- **纯中文标题**：二级及以下标题**必须**使用纯中文。
  - ❌ 错误：`## 简介 (Introduction)`
  - ✅ 正确：`## 简介`
  - *例外：标题本身为英文专有名词时允许包含英文（如 `## 码点 (Code Point)`）。*

### 2.2 层级与叙述
- **推荐层级**：使用 `##` (H2) 和 `###` (H3) 划分主要章节，`####` (H4) 仅用于小段落分割。**严禁标题层级跳跃**（如 H2 下直接使用 H4）。
- **连贯叙述优先**：多使用完整的自然段落进行连贯叙述。严格控制列表和 Callout（提示块）的滥用，避免内容过度碎片化或变成单纯的“要点堆砌”。

## 3. 排版与内容规范

### 3.1 文本与引用
- **中英混排空格**：汉字与英文字母、汉字与数字之间**必须**保留一个半角空格。
  - ❌ 错误：`通过API获取2个数据`
  - ✅ 正确：`通过 API 获取 2 个数据`
- **内部双链引用**：引用项目内其他文档时，**严禁**使用相对路径或普通链接，**必须**使用双链语法：`[[uuid|文档标题]]`。
- **外部来源引用**：如果内容参考了外部资料，须在文章开头或引用处使用块引用标明来源：
  `> [文章标题](URL) (作者/网站名称, YYYY-MM-DD)`

### 3.2 文本强调与高亮
根据强调的内容类型和篇幅选择合适的标记（**注意：请严格控制使用频率，避免“满篇重点”导致视觉疲劳**）：
- **一般性强调**：使用加粗 `**文本**`。
- **特定单词/核心词汇重点**：使用黄色高亮 `==词汇==`。
- **短语或长句重点**：使用蓝色下划线高亮 `<u>这是一段需要划重点的长句子</u>`。

### 3.3 代码与提示块
- **代码规范**：所有代码块必须指定准确的语言标识符（如 ````go`）。过长的代码应进行折叠或仅摘录核心片段。
- **Callout (提示块)**：用于包裹**重点补充内容**或作为文档的**引申扩展**。
  - 格式：使用 `::: [!type] 纯中文标题`。
  - 要求：详细的写法、折叠形式和支持的类型列表，**必须**查阅并遵守本目录下的参考文档：[[callout-reference.md](./callout-reference.md)]。

## 4. 质量要求与发布自检

- **内容完整性**：逻辑通顺、解释详尽。**绝不要**为了图省事或追求篇幅短小而牺牲内容的完整性，或省略必要的上下文说明。
- **发布前自检清单**：
  - [ ] 确保无 Markdown 语法错误。
  - [ ] 确保标题层级无断层。
  - [ ] 确保所有代码块完全闭合。
  - [ ] 确保无行尾多余的空白字符。
