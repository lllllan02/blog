# Concept Assistant Examples

本文件提供可复制的“科普输出模板”与少量示例，用于 `concept-assistant` 生成文章/卡片类内容时直接套用。

## 输出模板（文章/卡片类）

```markdown
---
title: [概念名称]
aliases: [UUID v4]
date: [YYYY-MM-DD HH:mm:ss]
card: true
order: 100
tags:
  - [领域/技术标签]
---

## 一句话定义
[简洁直观的定义]
> [可选：生活化类比，仅当概念非常抽象时使用，否则删除]

## 核心原理 [可选]
[用通俗语言解释关键机制/步骤；核心链路不折叠，扩展细节可折叠]

:::: [!info]- 扩展内容（可选）
[补充性的实现细节、边缘案例、进一步阅读线索等]
::::

## 应用场景 [可选]
- [场景 1]
- [场景 2]

## 知识扩展
- [关联概念 1]：[一句话说明关系]
- [延伸话题 2]
```

## 示例 1：输入（用户请求）

```text
介绍：CAP 定理
```

## 示例 1：输出（结构示意）

- `## 一句话定义`：一句话说明 CAP 约束是什么
- `## 核心原理`：用分区发生时的取舍解释一致性/可用性与分区容忍
- `## 应用场景`：分布式系统设计决策（数据库/缓存/注册中心等）
- `## 知识扩展`：PACELC、线性一致性、共识算法
