# Article Condenser Reference

## 1. Formatting & Style

**Primary Rule**: All generated documents must strictly follow the project's central writing style guide:
👉 **[.cursor/skills/skill-writing-style/SKILL.md](../writing-style/SKILL.md)**

This includes:
- **Frontmatter**: Use the standard fields (`title`, `aliases`, `date`, `tags`, `card`, `order`).
- **Structure**: Use H2-H4 headings, lists, and callouts.
- **Code Blocks**: Use language tags and folding for long blocks (>10 lines).
- **Callouts**: Use standard types (`abstract`, `tip`, `warning`, etc.).

## 2. Specific Requirements for Condenser

### 2.1 Citation Style
Immediately after the frontmatter, provide the source link:

```markdown
> [Original Article Title](URL)

(Optional: A one-sentence summary or lead-in)
```

### 2.2 Rewriting Principles (Condensing Strategy)
- **Condense**: Do not translate word-for-word. Summarize the *intent* and *logic*.
- **No Fluff**: Remove introductions, "In this article...", "Conclusion", etc., unless they contain unique insights.
- **Focus**: Prioritize core concepts, definitions, and key takeaways.
