## 面试回答

> **面试官**：请简述一下 Go 语言中 defer 的执行顺序。

“`defer` 语句的执行顺序是**后进先出 (LIFO)** 的，也就是最后声明的 `defer` 会最先被执行。

当程序运行到一个 `defer` 语句时，它不会马上执行后面的函数，而是把这个函数压入到当前 Goroutine 的一个栈里面。等到外层函数快要执行结束，也就是遇到 `return` 语句或者发生 `panic` 的时候，Go 就会按照从栈顶到栈底的顺序，把这些延迟函数依次弹出来执行。

我们在实际开发中，通常会用 `defer` 来做一些收尾工作，比如关闭文件句柄、释放数据库连接、解锁互斥锁，或者用来捕获和处理 panic。”

## 系统讲解

### 核心机制
当 Go 执行到一个 `defer` 语句时，不会立即执行其后的函数，而是将该函数压入一个当前 Goroutine 的栈中。当外层函数执行结束（执行到 `return` 语句或发生 `panic`）时，Go 会按照从栈顶到栈底的顺序，依次弹出并执行这些被延迟的函数。

### 代码示例
```go
func main() {
    defer fmt.Println("First")
    defer fmt.Println("Second")
    defer fmt.Println("Third")
    // 输出顺序：Third -> Second -> First
}
```

### 常见追问 (Bonus)
- **追问 1**：`defer` 里的函数参数是什么时候求值的？
  - **答**：在 `defer` 声明时就会立即求值，而不是在执行时求值。
- **追问 2**：`defer` 能否修改有命名返回值的函数的返回值？
  - **答**：可以，因为 `defer` 执行在 `return` 赋值之后、真正返回之前。
